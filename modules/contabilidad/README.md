# Contabilidad

Configuración → Términos de pago permite crear y editar términos con un único campo: Nombre. Tiene un listado con búsqueda y paginación y una vista de formulario independiente. Los registros se pueden seleccionar desde las cotizaciones de Ventas.

El catálogo comienza vacío. Esta etapa no incluye plazos, cuotas ni cálculos de vencimientos.

Para instalar únicamente el catálogo en otro entorno:

```powershell
& C:\xampp\php\php.exe php/install-accounting.php
```

La instalación de Ventas también crea la tabla de términos de pago.
